# Шёпот

Голосовой ввод для Windows в духе [Whisperly](https://whisperly.io/): зажали
горячую клавишу, продиктовали мысль — в активное окно вставляется готовый текст,
а не сырая расшифровка. Работает в любом приложении, где есть поле ввода.

## Что умеет

| | |
|---|---|
| **Режимы** | `Чистовик` — убирает «эээ», запинки и повторы, расставляет пунктуацию. `Как есть` — сырая расшифровка. `Перевод` — говорите на одном языке, вставляется на другом |
| **Тон** | Сохранить мою манеру / Нейтральный / Разговорный / Деловой |
| **Словарь** | Имена, бренды и термины, которые всегда пишутся одинаково |
| **Своё правило** | Произвольная добавка к промпту («обращайся на вы», «без эмодзи») |
| **Языки** | Распознавание ~99 языков с автоопределением, перевод на 20 языков из списка |
| **Горячая клавиша** | Переключатель или push-to-talk, любое сочетание, `Esc` отменяет |
| **Движки** | Облако OpenAI или локальный faster-whisper без интернета |
| **Вставка** | Через буфер обмена, набором с клавиатуры или только копирование |
| **История** | Последние диктовки, если текст не доехал до окна |

## Установка

Нужны Windows 10/11 (64-бит), микрофон и ключ OpenAI (ниже — где его взять).

### Быстрый путь: готовая сборка

1. Откройте [Releases](https://github.com/omertaevalibekai/shepot/releases/latest)
   и скачайте `Shepot-windows-x64.zip`.
2. Распакуйте в удобное место, например `C:\Program Files\Shepot` или
   `Документы\Shepot`.
3. Запустите `Shepot.exe`. Сборка не подписана сертификатом, поэтому Windows
   SmartScreen покажет предупреждение — **«Подробнее» → «Выполнить в любом
   случае»**.
4. Откроется окно **Ключи API** — вставьте ключ OpenAI, «Проверить»,
   «Сохранить». Готово.

Чтобы Шёпот стартовал вместе с Windows — включите это в настройках. Python
для сборки не нужен. Локальное распознавание (без интернета) в сборку не
входит — для него ставьте из исходников, как ниже.

### Из исходников

Если хотите менять код или нужен локальный режим.

#### 1. Python

Скачайте Python 3.11 или новее с [python.org/downloads](https://www.python.org/downloads/)
и запустите установщик. **На первом экране отметьте галочку «Add python.exe to
PATH»** — без неё команды ниже не найдут Python.

Проверка — в PowerShell:

```powershell
python --version      # Python 3.11.x или новее
```

#### 2. Шёпот

Либо через git:

```powershell
git clone https://github.com/omertaevalibekai/shepot.git
cd shepot
```

либо без git: на странице репозитория **Code → Download ZIP**, распакуйте
архив и откройте PowerShell в распакованной папке (в Проводнике: Shift + правый
клик по пустому месту → «Открыть окно PowerShell здесь»).

#### 3. Зависимости и ярлыки

```powershell
pip install -r requirements.txt
python tools\make_icon.py
python tools\create_shortcuts.py
```

Появятся ярлыки «Шёпот» на рабочем столе и в меню «Пуск». Дальше запуск —
обычным двойным кликом, без консоли и без команд.

#### 4. Первый запуск

Запустите ярлык. Значок появится в системном трее (у часов; если не видно —
в стрелке «^»), и сразу откроется окно **Ключи API**. Вставьте ключ OpenAI,
нажмите «Проверить», потом «Сохранить» — можно диктовать.

## Ключ OpenAI

Шёпот распознаёт речь и чистит текст через API OpenAI, поэтому нужен ваш
собственный ключ. Подписка ChatGPT Plus для этого не подходит — API оплачивается
отдельно, по факту использования.

1. Войдите на [platform.openai.com](https://platform.openai.com/).
2. **Settings → Billing** — пополните баланс. Без баланса ключ создастся, но
   запросы будут отклоняться с ошибкой лимита.
3. [**API keys**](https://platform.openai.com/api-keys) → **Create new secret
   key** → скопируйте ключ (`sk-…`). Он показывается один раз.
4. В Шёпоте: правый клик по значку в трее → **Настройки → Ключи API** →
   вставьте → «Проверить» → «Сохранить».

Сколько стоит — по [тарифам OpenAI](https://openai.com/api/pricing/): платите
за минуты распознанной речи и за небольшой запрос на чистку текста. Для
обычной диктовки это небольшие суммы; расход видно в **Settings → Usage**.

### Где хранится ключ

Ключи вводятся в самом приложении: правый клик по значку в трее → **Настройки →
Ключи API**. На первом запуске окно откроется само, потому что без ключа
диктовать нечем.

Кнопка «Проверить» рядом с полем делает живой запрос и сразу говорит, в чём
дело: ключ не принят, кончился лимит, нет интернета или всё в порядке.

Ключи шифруются механизмом Windows DPAPI и лежат в
`%APPDATA%\Shepot\secrets.dat`. Расшифровать их может только ваша учётная
запись на этой машине — скопированный файл на другом компьютере бесполезен, и
в открытом виде ключ на диск не пишется. Если у вас уже прописана переменная
среды `OPENAI_API_KEY`, она подхватится сама, а ключ из приложения её перекроет.

Нужен только ключ OpenAI. Anthropic — необязательный, для тех, кто выберет
Claude для обработки текста.

## Запуск

Ярлык, либо:

```powershell
python -m shepot          # с консолью, видно ошибки
```

Приложение живёт в системном трее. Клик по значку — начать или закончить
диктовку, правый клик — меню с режимами, историей и настройками. Второй запуск
не плодит копии: сработает уже открытый экземпляр.

Чтобы «Шёпот» поднимался вместе с системой, включите «Запускать вместе с
Windows» в настройках — пропишется в `HKCU\...\Run`.

## Сборка в .exe

Если Python на машине ставить не хочется — соберите автономную версию:

```powershell
python tools\build_exe.py
python tools\create_shortcuts.py     # переведёт ярлыки на .exe
```

Получится `dist\Shepot\Shepot.exe`; папку можно целиком перенести на другой
компьютер. Локальное распознавание в сборку не попадает — faster-whisper тянет
за собой модели и CUDA, для него запускайте из исходников.

Сборка не подписана сертификатом, поэтому при первом запуске SmartScreen
покажет предупреждение — «Подробнее» → «Выполнить в любом случае».

## Как пользоваться

1. Поставьте курсор в любое поле ввода — почта, мессенджер, редактор кода.
2. `Ctrl+Space` — появляется индикатор с дорожкой звука.
3. Говорите.
4. `Ctrl+Space` ещё раз — через пару секунд текст уже в поле.

`Esc` во время записи отменяет её. Если сочетание конфликтует с вашими
программами (`Ctrl+Space` занят в некоторых IDE и переключателях раскладки) —
поменяйте его в настройках, поле само запишет нажатое.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| `python` не найден | Переустановите Python с галочкой «Add python.exe to PATH» и откройте новое окно PowerShell |
| Ошибка при установке `PyAudio` | Обновите pip: `python -m pip install --upgrade pip`, затем повторите `pip install -r requirements.txt` |
| «Ключ не принят» | Ключ скопирован не целиком или удалён на platform.openai.com — создайте новый |
| «Кончился лимит» / 429 | Пополните баланс в Settings → Billing |
| Горячая клавиша не срабатывает | Сочетание занято другой программой — поменяйте в Настройках |
| Текст не вставляется в окно | Окно запущено от администратора — см. «О чём стоит знать» ниже |

Подробности ошибок видно, если запустить с консолью: `python -m shepot`.

## Сколько это занимает

Замеры автора, 10 секунд речи, облачный режим:

| Этап | Время |
|---|---|
| Распознавание (`gpt-4o-transcribe`) | 1,1–2,2 с |
| Обработка текста (`gpt-4o-mini`) | 1,3–1,7 с |
| **От конца записи до текста в окне** | **~3,3 с** |

Соединения к API открываются на старте приложения и при смене настроек — без
этого первая диктовка занимала бы на 9–10 секунд больше из-за TLS-рукопожатия.

## Локальный режим

Настройки → Движки → Распознавание → «Локально». Понадобится:

```powershell
pip install faster-whisper
```

Модель скачается при первом запуске и дальше держится в памяти. На видеокарте
с 6 ГБ памяти разумный потолок — `small` или `medium` в `float16`; `large-v3`
туда не поместится. Без видеокарты NVIDIA модель работает на процессоре,
но заметно медленнее — начните с `base` или `small`. Постобработку текста при этом можно выключить
(«Без обработки») — тогда интернет не нужен совсем, но останется сырая
расшифровка без чистки.

## Обработка через Claude

Настройки → Движки → Обработка текста → «Anthropic (Claude)». Нужен пакет
`anthropic` (`pip install anthropic`) и ключ в «Настройки → Ключи API».

По умолчанию стоит `claude-opus-5`. Запрос идёт с минимальным усилием
(`effort: low`), иначе модель думает дольше, чем длится сама диктовка, и
включён серверный запасной маршрут (`fallbacks: "default"`) — если запрос
отклонён классификатором, он автоматически уходит на другую модель. Для
диктовки заметно быстрее и дешевле `claude-haiku-4-5`: поменяйте строку модели
в том же поле.

## О чём стоит знать

- **Окна с правами администратора.** Windows не даёт обычному процессу слать
  ввод в окна, запущенные от админа. Если диктуете в такое окно, текст
  останется в буфере — вставьте вручную, либо запускайте «Шёпот» тоже от
  администратора.
- **Буфер обмена.** В режиме «Через буфер обмена» прежнее содержимое
  возвращается по таймеру (по умолчанию 0,6 с) — узнать, что приложение уже
  прочитало буфер, Windows не позволяет. Если медленная программа вставляет
  старое содержимое, увеличьте задержку в настройках или переключитесь на
  «Набором с клавиатуры»: там буфер не трогается вообще.
- **Набор с клавиатуры** медленнее вставки и в терминалах с включённым
  «умным» автодополнением может вести себя неожиданно.
- **Звук никуда не сохраняется** — запись живёт в памяти до конца расшифровки.
  В облачном режиме аудио уходит в OpenAI, в локальном не покидает машину.
  История хранит только текст, в `%APPDATA%\Shepot\history.json`.

## Устройство проекта

```
shepot/
  config.py        настройки в %APPDATA%\Shepot\config.json
  secrets.py       ключи API, зашифрованные DPAPI
  audio.py         запись с микрофона, 16 кГц моно
  stt.py           распознавание: OpenAI или faster-whisper
  polish.py        сборка промпта и постобработка текста
  providers.py     клиенты API, их прогрев и проверка ключей
  inserter.py      доставка текста: буфер обмена или SendInput
  hotkeys.py       глобальные горячие клавиши
  hud.py           индикатор поверх окон
  settings_ui.py   окно настроек
  history_ui.py    окно истории
  resources.py     доступ к assets/ из исходников и из .exe
  startup.py       автозапуск через реестр
  app.py           контроллер и трей
  __main__.py      точка входа, единственный экземпляр
tools/
  make_icon.py         рисует assets/shepot.ico
  create_shortcuts.py  ярлыки на рабочем столе и в «Пуске»
  build_exe.py         сборка автономного Shepot.exe
```
