**What's new**

- **English interface.** Shepot now speaks English and Russian: the tray menu, the island, settings, history, stats and the project jump. By default it follows the Windows language; switch it in Settings → General.
- **New settings.** Rebuilt in the style of iOS settings: sections with colored icons on the left, grouped options on the right, switches, segmented controls, a search box, and the dictionary as tags you can add and remove. Options that don't apply right now are hidden. Changes are saved when you press Done or close the window.
- **New icon.** A light voice wave that turns into a text cursor, on black — in the taskbar, Start menu and tray. In the tray the cursor shows the state: blue — ready, orange — recording, yellow — processing.
- **Reply to Claude Code by voice.** Press `Ctrl+Alt+Space`, speak, press it again: the text goes to the terminal of the Claude Code session that is waiting for you, and is sent with Enter. No window switching; the island shows which session you're answering.
- **Window context is off by default.** With it on, Shepot sends the window title and the text of the field you dictate into to the model, so names are spelled right. That's your conversation, so it's now your call: Settings → Text → “Use the window's text”.

**Update:** quit Shepot (right-click the tray icon → Quit), download `Shepot-windows-x64.zip`, unpack it over the old folder and run `Shepot.exe`. Your settings and keys stay.

The build isn't code-signed, so Windows SmartScreen shows a warning: “More info” → “Run anyway”.

**Что нового**

- **Английский интерфейс.** Шёпот говорит по-русски и по-английски: меню значка, остров, настройки, история, статистика и прыжок в проект. По умолчанию язык как в Windows; переключается в «Настройки → Основное».
- **Новые настройки.** Окно пересобрано в духе настроек iOS: разделы с цветными значками слева, группы справа, переключатели, сегменты, поиск, словарь «пилюлями», которые добавляются и удаляются. Пункты, которые сейчас не действуют, скрыты. Изменения сохраняются по «Готово» или при закрытии окна.
- **Новый значок.** Светлая волна голоса переходит в текстовый курсор на чёрном — в панели задач, «Пуске» и трее. В трее курсор показывает состояние: синий — ждёт, оранжевый — пишет, жёлтый — обрабатывает.
- **Ответ Claude Code голосом.** `Ctrl+Alt+Пробел`, продиктовать, ещё раз: текст уходит в терминал сессии Claude Code, которая ждёт ответа, и отправляется Enter. Окно переключать не нужно, остров показывает, кому вы отвечаете.
- **Контекст окна по умолчанию выключен.** Со включённым Шёпот отправляет модели заголовок окна и текст поля, куда вы диктуете, чтобы имена писались правильно. Это ваша переписка, поэтому включать решаете вы: «Настройки → Текст → Учитывать текст окна».

**Обновление:** закройте Шёпот (правый клик в трее → Выход), скачайте `Shepot-windows-x64.zip`, распакуйте поверх старой папки и запустите `Shepot.exe`. Настройки и ключи сохранятся.

Сборка не подписана сертификатом, поэтому Windows SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».
