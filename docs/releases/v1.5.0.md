**What's new**

- **Dark settings.** The settings window is dark by default, with system iOS colors and a dark Windows title bar to match. Prefer light, or want it to follow Windows? Settings → General → Appearance → Theme.
- **More polished settings.** Segmented controls with a sliding selection, hotkeys shown as real keycaps, a card for the app at the top of General, a live preview of the recording island on the Hotkeys page, smooth transitions between sections, and pop-up menus marked the iOS way.

**Update:** quit Shepot (right-click the tray icon → Quit), download `Shepot-windows-x64.zip`, unpack it over the old folder and run `Shepot.exe`. Your settings and keys stay.

The build isn't code-signed, so Windows SmartScreen shows a warning: “More info” → “Run anyway”.

**Что нового**

- **Тёмные настройки.** Окно настроек по умолчанию тёмное, в системных цветах iOS и с тёмной рамкой Windows в тон. Больше нравится светлое или как в Windows — «Настройки → Основное → Оформление → Тема».
- **Настройки аккуратнее.** Сегменты с плавно переезжающим выбором, горячие клавиши в виде настоящих клавиш, карточка приложения наверху «Основного», живой остров записи на странице горячих клавиш, плавная смена разделов и всплывающие списки с пометкой, как в iOS.

**Обновление:** закройте Шёпот (правый клик в трее → Выход), скачайте `Shepot-windows-x64.zip`, распакуйте поверх старой папки и запустите `Shepot.exe`. Настройки и ключи сохранятся.

Сборка не подписана сертификатом, поэтому Windows SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».
