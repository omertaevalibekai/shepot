**What's new**

- **Dark settings.** The settings window is dark by default, with system iOS colors and a dark Windows title bar to match. Prefer light, or want it to follow Windows? Settings → General → Appearance → Theme.
- **More polished settings.** Segmented controls with a sliding selection, hotkeys shown as real keycaps, a card for the app at the top of General, a live preview of the recording island on the Hotkeys page, smooth transitions between sections, and pop-up menus marked the iOS way.

**Fixes**

- **No more minutes of "processing".** If the server doesn't answer, Shepot gives up after 30 seconds (longer for long recordings) instead of waiting up to 4 minutes per request. If speech was already recognized and only the clean-up hangs, the raw text is inserted with a warning.
- **Esc cancels processing too.** While Shepot waits for the server, Esc frees the hotkey at once; a late answer is saved to History instead of being typed.
- **Clear error messages.** Instead of raw API replies with JSON you see what happened: balance used up, too many requests, key not accepted, server unavailable, no internet.
- **Error log.** Tray menu → Error log…: the full original errors, with API keys cut out and without your dictated text. Attach it when reporting a problem.
- Clean-up failures no longer lose the transcript; microphone, clipboard, admin-window and Claude Code bridge fixes.

 quit Shepot (right-click the tray icon → Quit), download `Shepot-windows-x64.zip`, unpack it over the old folder and run `Shepot.exe`. Your settings and keys stay.

The build isn't code-signed, so Windows SmartScreen shows a warning: “More info” → “Run anyway”.

**Что нового**

- **Тёмные настройки.** Окно настроек по умолчанию тёмное, в системных цветах iOS и с тёмной рамкой Windows в тон. Больше нравится светлое или как в Windows — «Настройки → Основное → Оформление → Тема».
- **Настройки аккуратнее.** Сегменты с плавно переезжающим выбором, горячие клавиши в виде настоящих клавиш, карточка приложения наверху «Основного», живой остров записи на странице горячих клавиш, плавная смена разделов и всплывающие списки с пометкой, как в iOS.

**Исправления**

- **Больше никаких минут «обработки».** Если сервер не отвечает, Шёпот сдаётся через 30 секунд (на длинной записи дольше), а не ждёт до 4 минут на каждый запрос. Если речь уже распознана и зависла только чистка, вставляется сырой текст с предупреждением.
- **Esc отменяет и обработку.** Пока Шёпот ждёт сервер, Esc сразу освобождает горячую клавишу; поздний ответ попадёт в Историю, а не напечатается.
- **Понятные ошибки.** Вместо сырого ответа API с JSON — что случилось: баланс исчерпан, слишком много запросов, ключ не принят, сервер недоступен, нет интернета.
- **Журнал ошибок.** Меню значка → «Журнал ошибок…»: исходные ошибки целиком, без ключей API и без продиктованного текста. Его можно приложить к сообщению о проблеме.
- Сбой чистки больше не теряет распознанный текст; исправления микрофона, буфера, окон администратора и моста Claude Code.

 закройте Шёпот (правый клик в трее → Выход), скачайте `Shepot-windows-x64.zip`, распакуйте поверх старой папки и запустите `Shepot.exe`. Настройки и ключи сохранятся.

Сборка не подписана сертификатом, поэтому Windows SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».
